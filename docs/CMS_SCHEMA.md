# CMS contract — M3 implementation

PostgreSQL is the source of truth. Every protected read/mutation reloads the active account and role from the database; client role claims are never authoritative. Administrators manage catalogue/media/pages/projects and operations. Editors draft their own articles; administrators publish/schedule them.

| Entity              | Implemented contract                                                                                                                                                                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| User / Role         | Bcrypt hashes, active ADMIN/EDITOR accounts, no public registration/default password. Self-demotion/disable is refused; serializable last-admin checks protect concurrent changes.                                                                        |
| Post / PostRevision | Allowlisted structured blocks, taxonomy, product links, SEO/social fields and optimistic version. Immutable publication snapshots separate live content from working edits. User excluded restore/history UI.                                             |
| PublicationJob      | Exact saved version, UTC run/attempt timestamps, durable states, bounded retries and protected idempotent worker. Draft edits invalidate schedules and expose review state.                                                                               |
| Product             | Structured paragraphs/specifications/FAQs, image and usage alt, applications, related products, SEO, ordering and explicit admin publication. UpdatedAt compare-and-swap prevents stale saves/archive.                                                    |
| Project             | Structured challenge/solution/outcome, optional date/location, media/products and client permission. Save returns to private draft; approval checks saved timestamp, content, image alt and permission. Public reads require publishedAt plus approvedAt. |
| Media               | Validated decoded images, optimized WebP, provenance/default alt/dimensions/focal point, private source preservation. Upload-new/select-image replacement keeps old references intact; archive checks references under a transaction lock.                |
| PageContent         | Controlled 1–20 text sections, version and SEO. Save returns to private draft; publication checks version. Home/About/Services render supplemental approved sections while preserving source layout/claims.                                               |
| SiteSettings        | Contact/location, editable statistic values/labels, award wording, validated HTTPS social profiles and SEO defaults. Shared header/footer read these fields.                                                                                              |
| Redirect            | Safe same-site paths, unique source, permanent/temporary flag, bounded chain resolution and serializable cycle checks. Unknown legacy paths pass through the public redirect resolver before 404.                                                         |
| Inquiry             | Private personal information and consent; administrator-only inbox/detail/status management. Audit tracks only status transitions; retention policy/provider decisions remain release inputs.                                                             |
| AuditLog            | Actor/action/entity reference and bounded non-sensitive changes. Passwords, account contact fields and enquiry message content are omitted from operation audit payloads.                                                                                 |
| LoginThrottle       | Shared atomic account attempt window rather than process-local counters.                                                                                                                                                                                  |

Public selectors require PUBLISHED, publishedAt <= now and deletedAt = null. Articles additionally require a valid immutable published snapshot; projects require approval. Private previews require authentication, no-store and noindex. Structured text is escaped by React; arbitrary HTML/embeds are not accepted.

Publication is authorize → validate → compare saved version → transactionally write state/snapshot/audit → invalidate public paths. Schedule processing binds to the same saved version and never uses browser time. SEO advice is explanatory, not a ranking score.

Explicit CONTENT_SOURCE=seed remains a read-only public preview; database failures never fall back to it. Local media is in ignored storage. Production durable storage/backups, dependable scheduling trigger/secret, MFA/recovery, edge throttling and release UAT remain M4 gates. See M3_COMPLETION_QA.md for verification and operational limits.
